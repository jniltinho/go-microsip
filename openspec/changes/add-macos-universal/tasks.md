# Tasks

A task is checked only with evidence bound to a commit: a test and its run, a receipt under `docs/receipts/`, or a CI run. A sentence in the documentation never checks a task. Nothing here is implemented yet. The order of the groups is the plan; on 2026-11-13 the owner, away from the Mac, asked for what SSH alone allows meanwhile, so tasks of groups 3 to 6 that depend on no measurement of group 2 (the folders, the layering test, the static check, the keychain's command builder, the control endpoint) may be done before 2.7, and nothing that touches sound, a permission or a desktop session is. "The Mac" is the machine named by `GO_MAC_SSH`; "in a desktop session" means the packaged application opened with `open` in a session that is already logged in (design D10).
