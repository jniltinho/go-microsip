# M3: skins and refinement (2026-11-12)

Change `openspec/changes/migrate-to-go-wails`, section 5. The seven skins, layout B and the AAA refinement were built during M2 on the owner's request and merged then; this receipt records what M3 still needed, and the evidence each task's verification asks for. Nothing here is call evidence beyond the lab window run it names.

## What was added

- **State never by color alone, checked in every skin** (`frontend/scripts/prints.sh`): on the screens of a call state or an error, each label must start the text of an element that holds an icon directly. Twelve labels in seven skins.
- **Offline start of every skin** (`make go-offline-skins`, `build/qa/offline-skins.sh`): the built window in a container started with `--network none`, each skin saved as the setting, the page's own report (`--ui-trace`) naming that skin and the whole home screen; the built page scanned for anything loaded from outside itself.
- **`docs/themes.md`**: the seven edits a skin needs and the checks that catch a forgotten one.
- **`doctor` reports an unknown skin** (ui-themes, "Unknown skin in the configuration"): the window already started with System; the report now says so, without the value (`unknown_theme` in JSON).
- **Dark: hover** (the owner's note on the built window): `--btn-hover` was the color of a key at rest.
- **Bundled fonts** (task 5.4; the owner's decision of 2026-11-12: bundle them, good-looking and well defined): `frontend/src/fonts/` with Inter 4.1, DejaVu Sans 2.37, Liberation Sans 2.1.5 and JetBrains Mono 2.304, the unmodified files of the Debian 13 packages `fonts-inter-variable`, `fonts-dejavu-core`, `fonts-liberation` and `fonts-jetbrains-mono`, each with the package's copyright file. Every skin names a bundled family first, except Ubuntu, which keeps the system's Ubuntu font before Inter (that font is not bundled: its licence and name are Canonical's). `scripts/go-licenses.sh` writes the font licences into the third-party notices.
